核心功能

  • 资料录入与文本导入

    支持标题、正文、来源、标签等信息录入，自动创建全文索引

  • 全文检索与标签筛选

    基于 seekdb MATCH AGAINST 全文索引，支持中英文混合检索和相关性排序

  • 来源定位

    每条资料记录来源信息，检索结果清晰展示出处

  • 关联资料待办

    创建待办任务并关联到具体资料，方便追踪后续工作

  • 进度汇总

    按日期范围统计资料和待办数量，生成可复制的进度报告

技术架构

本项目使用 Python FastAPI 构建后端，前端采用原生 HTML/CSS/JavaScript， 数据库使用 seekdb MySQL 协议，全文检索通过 MATCH AGAINST 实现。

后端: FastAPI + PyMySQL
数据库: seekdb (MySQL 协议)
全文索引: MATCH(title, content) AGAINST(...)
前端: Jinja2 模板 + 原生 JavaScript
